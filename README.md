Sistema de Desconto

Este projeto foi feito em Python para calcular descontos de acordo com o valor de uma compra.

Descontos
Abaixo de R$ 200 → 5%
De R$ 200 a menos de R$ 300 → 10%
R$ 300 ou mais → 15%

O programa recebe o valor da compra, calcula o desconto e mostra o valor final.

Conceitos utilizados

input(), float(), if, elif, operadores relacionais e print().
